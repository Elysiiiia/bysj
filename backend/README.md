# 基于用户评论情感分析的商品个性化推荐系统

## 论文文本参考

### 课题描述

随着网络购物逐渐成为人们购买商品的重要方式，平台中的商品数量持续增加，用户在面对大量相似商品时往往需要花费较多时间进行筛选。传统推荐方式大多依据销量、价格或者基础点击记录给出结果，这类方法虽然能够在一定程度上缩小选择范围，但对用户真实偏好的把握还不够细。尤其是在手机这类参数复杂、品牌集中、评论量大的商品中，用户往往更看重其他消费者的实际使用感受，而这些信息主要分散在评论文本里。如果只看分数和销量，很多带有明显主观倾向的评价内容就难以被系统充分利用。

本课题围绕手机商品推荐场景展开，设计并实现了一个基于用户评论情感分析的商品个性化推荐系统。系统以商品评论、商品基础信息和用户行为数据为主要数据来源，在完成评论情感识别后，将情感得分与评分、价格区间、品牌偏好以及用户历史行为结合起来，生成更贴近用户兴趣的推荐结果。除推荐功能外，系统还提供评论管理、数据统计和可视化分析等功能，使平台能够从评论数据中提取更直观的信息，为用户选购和后台管理都提供支持。

### 摘要参考

针对电商平台中商品数量多、用户筛选成本高以及传统推荐结果不够贴合个人偏好这一问题，本文结合用户评论文本信息与用户行为数据，完成了一个基于用户评论情感分析的商品个性化推荐系统的设计与实现。系统以前后端分离思路进行开发，后端采用 Spring Boot、MyBatis-Plus 与 MySQL 搭建服务环境，围绕用户管理、商品管理、评论管理、情感分析、行为记录和推荐计算等模块展开。评论数据进入系统后，会先结合评分与评论内容完成情感判断，得到对应的情感标签和情感分值，再将结果回写到商品统计信息中，用于更新商品的平均评分、评论数量和整体情感倾向。

在推荐实现上，系统没有只依赖单一指标，而是把用户近期行为、评论情感结果、商品价格差异、品牌相似度和评分情况一起纳入计算。对已有行为记录的用户，系统根据浏览、点赞和评论等信息提取兴趣偏向，再对候选商品进行综合排序；对缺少历史数据的新用户，则优先推荐情感表现较好、评分较高且评论量相对充足的商品，以保证推荐结果具备基本可用性。与此同时，系统还提供品牌情感分布、价格区间满意度、评论趋势和关联关系等分析接口，便于对评论数据和商品数据做进一步观察。

从实现结果来看，该系统能够较完整地覆盖评论采集后的存储、情感处理、统计分析和个性化推荐流程，把原本分散在评论文本中的主观意见转化为可参与计算的数据。相比只依据销量或评分排序的方式，这种做法更能体现用户对商品真实使用体验的反馈，也使推荐结果具备更强的针对性和一定的实用价值。

### 研究背景与意义

当前电商平台中的商品更新速度很快，同一类产品下往往聚集了大量品牌和型号，用户在挑选商品时容易陷入信息过载。手机商品尤其明显，因为这类产品既有价格差异，也有配置差异，用户在购买前通常会反复查看评论，希望从他人的使用反馈中判断一款产品是否适合自己。评论文本中包含了对续航、拍照、性能、外观和性价比等内容的直接评价，这些内容比单纯的星级分数更具体，也更接近用户的真实感受。

从实际应用看，把评论情感分析引入推荐系统有较强的现实意义。一方面，平台可以借助情感结果更准确地识别商品口碑变化，不再只依赖表面的销量和评分；另一方面，推荐结果能够更充分地反映用户的关注重点，使用户在较短时间内接触到更符合自己偏好的商品。对于管理者而言，评论与情感数据还能够作为运营参考，用来观察品牌表现、价格区间反馈和用户满意度变化，这使系统不仅具备推荐功能，也具有一定的数据分析价值。

### 系统实现内容

本系统以手机商品推荐为主要应用对象，数据库中包含用户表、商品表、评论表和用户行为表。商品表保存品牌、标题、价格、销量、店铺和情感得分等信息，评论表保存评论内容、评分、规格、评论时间以及情感标签，用户行为表则记录用户在平台中的浏览或偏好动作。这些数据共同构成了推荐计算和统计分析的基础。

在评论处理部分，系统支持评论分页查询、评论新增与修改，并在保存评论时调用情感分析逻辑，对评论内容和评分进行联合判断。分析完成后，系统会得到对应的情感分数与正向、中性、负向标签，然后自动更新该商品的平均评分、评论数和整体情感得分。这样处理之后，商品信息不再只是静态展示数据，而会随着评论变化不断调整。

在推荐部分，系统会优先读取用户近期行为记录。如果用户已经产生过浏览、点赞或者评论行为，系统就把这些行为转化成不同权重，再结合商品品牌、价格差异、情感得分和平均评分进行相似度计算，最后给出排序后的推荐列表。如果用户缺少有效行为数据，系统会采用冷启动方式，从情感分数、平均评分和评论数量表现较好的商品中生成推荐结果。这种处理方式虽然实现上相对直接，但已经能够较好体现个性化推荐的基本思路。

在数据分析部分，系统提供首页统计、后台统计和可视化分析接口，能够展示商品数量、评论数量、正向评论占比、品牌情感分布、价格区间满意度、月度评论趋势以及商品之间的关联关系。这些结果可以帮助使用者从更整体的角度观察评论数据变化，也有助于说明评论情感信息在推荐系统中的作用并不是孤立存在的，它同时服务于统计分析和推荐决策。

### 技术路线参考

本课题在实现时采用 Java 语言与 Spring Boot 框架搭建后端服务，使用 MyBatis-Plus 完成数据库访问，利用 MySQL 存储用户、商品、评论和行为数据。在接口设计上，系统通过控制器向前端提供商品查询、评论管理、推荐结果获取和分析数据展示等服务。为了保证登录后的访问控制，系统还引入了基于 JWT 的身份认证方式，对普通用户和管理员的操作进行区分。

情感分析部分主要面向评论内容展开处理，系统在评论写入时同步完成情感标签和情感得分的生成，再把结果反馈到商品维度的数据统计中。推荐计算部分则依据用户近期行为构造偏好信息，并通过商品之间的相似度计算生成候选结果。整个流程从数据存储、情感处理到推荐输出之间衔接较紧，能够形成一个相对完整的业务闭环。

### 结论参考

本课题完成了一个面向手机商品场景的个性化推荐系统，并把用户评论中的情感信息纳入推荐过程。系统在结构上覆盖了用户管理、评论管理、行为记录、情感分析、推荐计算和数据可视化等内容，能够满足毕业设计对系统设计、功能实现和数据应用分析的基本要求。实际实现表明，评论情感信息在推荐场景中具有较高的利用价值，它能够补充传统推荐中过分依赖销量和评分的问题，使推荐结果更贴近用户在真实消费中的关注点。

当然，当前系统仍有进一步完善空间。现阶段的推荐方法主要依据规则与相似度计算完成，情感分析也偏向基础实现，后续还可以继续结合更细粒度的文本特征、更多类型的用户行为以及更加稳定的模型方法，对推荐精度和系统表现做进一步优化。
