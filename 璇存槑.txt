二、功能列表
--------------------------------------------------------
【用户前台】
  1. 登录 / 登出（角色：普通用户 / 管理员）
  2. 首页：推荐商品展示 + 数据概览统计
  3. 商品列表：卡片式展示，8 件/页，支持品牌筛选和关键词搜索
  4. 商品详情：图片、价格、规格、情感分析结果、用户评论（分页）
              + 相似商品推荐（基于品牌 + 价格 + 情感相似度）
  5. 个性化推荐：基于算法的推荐列表 + 算法步骤说明 + 浏览历史

【数据分析】
  6. 数据分析大屏（FineBI 风格，无滚动条，6 图一页）：
     - 各品牌销售量分布（横向条形图）
     - 价格区间分布（柱状图）
     - 评论情感倾向分布（环形图）
     - 月度评论数量与评分趋势（双轴折线 + 面积图）
     - 品牌综合评价雷达图（雷达图）
     - 评论高频词云（词云图）

  7. 关联分析1 — 品牌情感关联分析：
     统计各品牌正面/中性/负面评论占比，堆叠条形图展示品牌口碑对比
  8. 关联分析2 — 规格满意度关联分析：
     存储规格情感得分柱状图 + 价格区间情感折线图 + 评分散点图
  9. 关联分析3 — 协同评论关联分析：
     同用户评论商品对的桑基图 + 品牌共现热力图 + 关联规则列表

【后台管理】
  10. 控制台：统计数据概览 + 品牌商品分布 + 最近评论
  11. 商品管理：列表（搜索+分页）、新增、编辑、删除
  12. 评论管理：列表（搜索+分页）、新增（自动计算情感分）、编辑、删除
  13. 用户管理：列表（搜索+分页）、新增、编辑、删除

【推荐算法】
  14. 情感分析引擎：关键词匹配（正负面词库）+ 评分加权（0~1 情感分值）
  15. Item-CF 协同过滤：用户-商品稀疏矩阵 + 余弦相似度计算
  16. 情感增强推荐：融合品牌偏好 + 价格区间 + 情感分值
  17. 冷启动推荐：新用户综合热度 + 情感分 + 评分排序
  18. 混合推荐主函数：CF（60%）+ 情感（25%）+ 评分（15%）动态排序


三、技术框架
--------------------------------------------------------
【后端框架】
  - Python 3.10+
  - Flask 3.1.0（Web 框架，蓝图模块化路由）
  - MySQL（正式部署推荐，开发使用 SQLite3 替代）

【前端框架】
  - Bootstrap 4（响应式 CSS 框架）
  - ECharts 5（数据可视化图表）
  - ECharts WordCloud（词云插件）
  - jQuery（AJAX 与 DOM 操作）
  - Axios（HTTP 请求库）

【算法模块】
  - 情感分析：基于中文正负面关键词词典 + 星级评分加权
  - 协同过滤：基于物品的 Item-CF，余弦相似度
  - 关联分析：商品共现矩阵，类 Apriori 频繁项集挖掘

【设计风格】
  - 学术 / 研究风格，深蓝色侧边栏 + 白色卡片内容区
  - 左侧固定菜单导航，右侧滚动内容区
