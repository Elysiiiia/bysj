# 改造计划

## 阶段 1：基础拆分

- 建立 Spring Boot 后端。
- 建立 Vue 前端。
- 建立 FastAPI 情感服务。
- 建立 MySQL 表结构。

## 阶段 2：数据迁移

- 从原 SQLite 数据库导出 `users`、`phones`、`comments`、`user_behavior`。
- 导入 MySQL。
- 校验商品数、评论数、情感标签分布。

## 阶段 3：功能对齐

- 对齐 Flask 原首页、商品列表、详情页、推荐页。
- 对齐后台商品、评论、用户管理。
- 对齐大屏和三类关联分析图表。

## 阶段 4：增强

- 密码从明文升级为 BCrypt。
- 增加导入 CSV 的后端接口。
- 增加 Python 服务不可用时的提示和重试。
- 增加接口测试和前端构建检查。
